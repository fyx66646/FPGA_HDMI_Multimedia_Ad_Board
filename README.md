# FPGA_HDMI_Multimedia_Ad_Board
基于安路EG4S20 FPGA的多媒体数字传媒屏，上电自动扫描SD卡，经HDMI输出全彩画面与立体声伴音，实现图、音、字、效一体化广告轮播——无CPU、无操作系统，单芯片即插即播。  支持两挡分辨率BMP解析与硬件实时缩放，SDRAM双缓冲无撕裂切换；四轨音频循环轮播并跟随画面切换，内嵌中文字幕随歌单滚动；五种转场特效配合雪花、星空粒子氛围引擎；64点FFT实时频谱律动；中文菜单现场调节七项参数。  创新点：全扫描时渲染架构逐像素实时合成，零帧缓存往返、零显示延迟；线性擦除采用读侧双缓冲地址混合，两图同屏无黑场；粒子溶解以零存储哈希实现随机散布；五时钟域协同与多重看门狗保障7×24稳定运行。低成本FPGA完成解码、渲染与音视频输出全链路，断电无忧、换卡即换内容。
